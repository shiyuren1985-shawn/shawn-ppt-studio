# 媒体隔离与交付格式

## 所有对话隔离

不得让大尺寸或批量图片载荷进入根任务、用户直接创建的主对话，以及由主对话创建并长期保留的新测试任务或新对话。除非用户明确要求展示指定图片，否则这些主对话不得接收参考图、候选图、总览、缩略图、联系表预览、Base64、data URI、二进制内容或图片块。

ImageGen 在子 Agent 内按既有管线合同创建并保存图片；本规则不限制子 Agent 内生成或查看图片的数量。子 Agent 只向父级主对话返回路径、尺寸、哈希、状态或最小 JSON，不使用 `generatedImage(...)`、`image(...)` 或其他方式把图片载荷转发父任务。主对话不得打开、整段读取或复制子任务原始 `.jsonl` 找图片路径；读取或监控其他主对话必须使用 `includeOutputs=false` 或等效的仅文字摘要模式。优先使用纯文本回执；仍缺失时让原子 Agent 做无生图恢复，或运行 `scripts/recover_image_artifact.py`。

视觉检查与 Judge 必须照常在子 Agent 内执行；子 Agent 可以按正式工作合同打开联系表和必要单图。它只返回精简 JSON、报告路径、哈希和文字结论，不把图片回传父级主对话。不得在主对话中直接看图，也不得跳过原本需要的检查或声称通过未执行的视觉验收。

向用户只使用普通可点击文件链接，不使用 `![...](...)`、HTML 图片标签或其他图片嵌入。

## Fast8 两行九链接

完成后先由正式状态确定性生成唯一交付文本：

```bash
python3 scripts/build_fast8_delivery_message.py \
  --state "<project_dir>/state/style_run_state.json"
```

脚本写入 `state/delivery_message.md`，严格生成两行：第一行是`总览`，第二行横向合并 `A`、`B`、`C`、`D`、`E`、`F`、`G`、`H` 八个链接。随后执行：

```bash
python3 scripts/validate_delivery_text.py \
  --file "<project_dir>/state/delivery_message.md" \
  --require-link \
  --fast8-links-only \
  --project-dir "<project_dir>"
```

只有 `status=pass` 才能把该文件逐字发送。不得在两行链接前后添加状态、耗时、警告、索引、说明、问候或总结；任何增删都必须重新生成并校验。

## 其他模式

其他模式仍把完整最终草稿写入 `state/delivery_message.md`，运行 `validate_delivery_text.py --require-link` 后逐字发送。它们也只可使用普通链接，不可嵌入图片。
