# Shawn PPT Image

## 工作边界

交付完整 PPT 页面图片和总览，不组装 PPTX。保持三层分离：

1. 用内容合同冻结当前页事实、逐字文案、来源、资产和禁区。
2. 用页面导演确定关系命题、信息取舍、视觉工艺和空间组织。
3. 让 ImageGen 只执行已编译的页面任务，不承担合规审查或跨页推理。

不得把目标、估算、占位符或未确认内容写成已验证事实。不得用本地绘图、HTML、SVG、Pillow、PowerPoint 布局或程序叠字代替 ImageGen；`scripts/build_style_matrix.py` 只能排列完整页面。

## 选择模式

- 用户未指定模式时，输入恰好一页默认使用 `fast_8x1_diverse`；输入多页默认使用 `selected_style_expansion` 逐页制作。用户明确指定模式、页数、测试目的或先探索再选择时，服从用户要求。
- 单页 8×1 生成 A–H 八张和 2×4 总览。无风格定位图、也无色调要求时才默认 A–D 深色、E–H 浅色；有风格定位图时，除非用户另行指定，A–H 全部跟随其主画布背景色调，并在同一 tone 内探索不同排版与关系表达。
- 三个代表页定位同一视觉家族：使用 `fast_4x3`，生成 A–D 四个家族 × 三页。自由选页规则、锚点与跟随页依赖见 `references/4x3运行合同.md`。
- 多页逐页制作：使用 `selected_style_expansion`，见 `references/选定风格扩页.md`。有锚点时把它作为视觉家族输入；没有锚点时由视觉导演建立全稿文字视觉家族，所有页使用 `text_family`，不得把首张生成页自动变成后续锚点。
- 用户要求修改一张既有候选：使用正式 `single_image_edit` 控制面，不覆盖父图，不改变用户选择状态。
- 宿主要求删除正式候选及其过程文件：先调用 `scripts/plan_candidate_artifact_cleanup.py` 生成只读计划。部分删除只回收被正式 state 精确绑定的候选图片、任务、提示词载体和 claim/ticket/receipt；只要本次运行还保留任何候选，冻结页面合同、source snapshot、状态、素材与共享目录都必须保留，避免保留候选下一次刷新失效。删除最后一张仍存在的正式候选时，才允许把页面合同等随整个运行目录一起回收。宿主必须再次校验计划边界，并以可回滚方式移入废纸篓。
- 继续、恢复或定向修复既有运行：先读正式 state，再读 `references/阶段交接与源材料漂移.md`；不得擅自迁移合同版本或重编历史任务。

每次新运行创建独立 `project_dir`；旧候选和源文件只读保留。不要复用上一轮 Director 会话、路径、内容、锚点或状态。

## 按需读取

只读取当前阶段需要的文件，不预载未来阶段：

- 内容大纲、拆页、语言和双语：`references/内容规划规则.md`
- 参考图、锚点角色和附件边界：`references/参考图与约束分层.md`
- 空间组织与呼吸感：`references/空间节奏与视觉呼吸规范.md`
- 品牌与基础验收：`references/设计基础与品牌资产.md`
- 用户或大纲明确规定标题区：`references/全稿外壳与标题系统.md`
- 官方产品图、Logo 或可复用元素：`references/常用PPT元素资产库.md`，按需检索本地补充资产库
- 大纲指定 PDF/PPT/文档某页、网页或非光栅视觉来源：`references/视觉资产解析与冻结.md`
- 主对话媒体隔离与交付文本：`references/媒体隔离与交付格式.md`
- 精确 `transport=studio_app_server_v1` 或正式单图修改：`references/Studio运行例外.md`

Fast8 分阶段读取：

1. 准备、三位导演和派发：`references/Fast8准备与派发.md`
2. 图片开始返回、技术失败或恢复：`references/Fast8产物交接与恢复.md`
3. A–H 结算后唯一 Judge 与收口：`references/Fast8裁判与收口.md`
4. 需要健康报告、中央索引或批次复盘时：`references/运行监测与批次复盘.md`

## 共享硬边界

- 只允许当前页冻结合同决定该页标题、事实、对象和关系。其他页面、锚点、证据附件和历史运行不得补写或替换当前页内容。
- 把视觉参考默认视为 `style_anchor_only`：只传递视觉家族，不授权其标题、正文、对象、事实、页面结论或具体构图。新生成页不得累计为后续锚点。
- 背景色调优先级固定为：用户当前明确要求 > primary 风格定位图的主画布背景色调 > 无参考图时的管线默认值。该规则适用于 8×1、4×3、逐页扩页和单图修改；有参考图时不再机械执行深浅各半。
- 所有模式的冻结前输入枚举只做一次视觉资产解析：从目标页硬约束及其直接指向的页级资产索引解析真正要上屏的 Logo、产品图、照片、文档指定页或网页视口；非光栅来源统一通过 `scripts/materialize_visual_asset.py` 转为可追溯光栅，不扫描其他页面，不把普通 planning evidence 登记为 ImageGen 资产，也不增加 Director 或 Reviewer。Fast8 还必须在正式目录创建前完成这一步。
- 把必要事实/品牌资产作为明确附件角色传入；总附件上限为 5。资产库存在不等于当前页获得使用授权。
- 一份多语言大纲同时保存中文层、英文层和页级双语交付策略，不维护中文／英文／双语三份平行大纲。运行前按 `references/内容规划规则.md` 做一次确定性语言投影：中文或英文任务只把目标语言交给当前页；双语简单页生成一张同页配对图，双语复杂页生成中文、英文两个隔离兄弟页。不得把复杂页的中文页替换成纯英文页，也不得让两个兄弟任务互见另一语言的显示文案。
- `display_required` 逐字准确；`display_flexible` 完整保留原意，允许自然压缩。标题只来自当前页明确标题；缺少副标题时不得从锚点或证据图补写。
- 让候选在用户仍开放的关系表达、粗粒度空间拓扑和工艺轴上真实分离；不要只换底色或措辞，也不要为了差异破坏事实、品牌、锚点家族或用户指定骨架。
- 当前 prompt v4/v6 的最终 Style Job 由共享编译器在页级内容、资产和修复说明全部追加后，只在 `imagegen_prompt` 末尾加入一次固定的 pre-render subtraction check；Director、Chrome、Judge 与 `overall_requirements` 不得重复承载。该检查不限制容器数量，也不得牺牲内容完整性、阅读顺序、视觉层级、信息密度或候选空间差异。
- 质量门保持少而稳定：检查事实与来源、逐字必显内容、必要资产、文件/尺寸/比例、严重可观察的构图退化和候选真实分离。轻微瑕疵、主观偏好或“还可以更漂亮”不触发自动返修。
- 只保留一个隔离 Judge 和一次有界定向修复；不增加第二 Reviewer、逐页 LLM Worker、平行状态机、重复接触表或无意义哈希门。`candidate_ready` 不等于用户批准或选定。
- 使用正式 state、冻结 source packet、正式 job、输入指纹、唯一 receipt 和原子状态更新。机械执行共享中央 JIT cap5，遵循 `claim → ImageGen → savedPath/receipt → release`；不得重复生图或另建信号量。
- 三位短导演只读本轮冻结输入并并行写各自 raw 文件；控制面只补机械默认值，不替导演编造事实或语义。

## 媒体与交付

主对话只做调度和文件/状态检查，不接收批量图片、缩略图、Base64、Data URL、联系表或原始工具输出。图片执行与视觉检查留在子 Agent；子 Agent 只回传精简文字、JSON、绝对路径、尺寸、哈希和状态。监控其他任务时使用 `includeOutputs=false`，不得读取原始 `.jsonl` 找图。

交付总览或向外部 PPTX/PDF 组装器交接时，只提供最终清单和原图绝对路径，不得为了建立 `final`、`delivery` 或 `origin_image` 汇总目录而复制内容相同的候选图。下游必须从清单引用唯一物理源；若旧工具要求独立图片目录，应先改造该工具，不得以成稿汇总为由复制原图。

正常生成只允许一个机械图片执行者。完成后按 `references/媒体隔离与交付格式.md` 生成并校验最终交付文本，向用户提供普通可点击文件链接。视觉检查与唯一 Judge 必须照常执行，不得因媒体隔离而跳过或伪造通过。
