# 逐页制作与选定风格扩页

## 边界

多页请求在用户未指定其他模式时建立 `run_mode=selected_style_expansion` 运行。用户提供锚点时沿选中方向扩页；没有锚点时由视觉导演建立文字化全稿视觉家族并直接逐页制作。两者共用同一薄适配器，不复制来源、正式 job、派发、结算、PNG、恢复、租约或 handoff 状态机。

新运行固定使用 `content_contract_version=2`、`prompt_contract_version=4`。已经落盘的 v1/v2 内容合同、v3/v4 prompt、逐页 Worker ticket 或旧状态只按原文件恢复；不得迁移、重编或用新字段覆盖。

## 视觉家族来源与锚点授权

允许零至两张锚点：

- 零锚点：`visual_family_source=director_defined_text_family`。视觉导演根据用户审美要求、品牌约束与全稿内容建立 `selected_style_family_contract`；所有页确定性使用 `anchor_input_mode=text_family`。不得先生成一页充当隐式锚点，也不得累计新生成页。
- 一至两张锚点：`visual_family_source=raster_anchor`。必须且只能有一张 primary，可选一张 supporting；按下列授权范围处理。

先明确选中候选的授权范围：

- `style_anchor_only`：默认。锚点只是视觉风格证据，不表示其中的文字、事实、对象、构图或标题区获批；锚点本身不必先成为事实正确的最终页面。
- `final_page_and_anchor`：锚点既是风格证据，也是本轮最终页面。该页必须像其他最终页一样单独经过当前页事实、标题、资产与视觉 QA。

锚点只锁定同一视觉家族的色彩与明暗、字体气质、材质、图像工艺、完成度，以及**已获明确授权时**的页面外壳。除非用户另行指定，整轮背景 tone 跟随 primary 锚点的主画布背景，不逐页翻转深浅；用户明确色调要求优先。它不锁定抽象程度、信息密度、内容区拓扑、图文比例、视觉媒介或锚点中的对象。不同页面可按内容使用抽象表达、图表、工程图、写实照片或混合方式。

用户提供锚点时默认一张 `primary`，可选一张 `supporting`；不要把第三张普通风格图塞入默认集合。每页由视觉导演明确选择：

- `anchor_input_mode=raster`：把固定的 primary 和可选 supporting 锚点作为风格附件。
- `anchor_input_mode=text_family`：不传锚点原图，只继承文字化 `selected_style_family_contract` 与本页 `page_adaptation_brief`。视觉导演只在锚点媒介与当前页表达存在明确硬冲突时选择它；不得根据尚未解析的 Logo、产品图或计划资产猜测附件容量。完整幻灯片锚点含旧标题或正文并不单独构成降级理由；prompt v4 已要求本页标题、事实、对象和关系只来自当前页冻结合同。脚本不读取锚点文字或增加额外审查。

当前页事实、关系、语言、品牌与必要资产始终高于锚点。不得把锚点旧标题、旧数字、旧对象或其他页词汇写成否定清单。新生成的 P10 不得自动成为 P11 的锚点；除非用户另行明确授权，扩页不累计学习。

## 初始化与规范目录

先为本轮创建全新的、不复用既有候选的 `project_dir`。确定性 initializer 必须一次创建：

权威来源若是一份同时保存完整中文层、完整英文层和 `bilingual_strategy` 的多语言大纲，先按 `内容规划规则.md` 运行 `scripts/project_multilingual_outline.py`，再把生成的本轮 JSON 作为 `--source-file`。中文／英文投影仍是一逻辑页一物理页；双语投影中的复杂页会出现如 `09-ZH,09-EN` 的两个物理页码。投影 JSON 只属于本轮冻结输入，权威内容仍只在原大纲维护。

```bash
python3 scripts/init_task_dir.py \
  --output-root "<output_root>" \
  --task-name "<新任务名>" \
  --run-mode selected_style_expansion \
  --selected-style "<有锚点时填写 A-H；无锚点时可省略>" \
  --page-ids "<完整规范页序>" \
  --source-file "<权威来源绝对路径>" \
  --slide-identity-file "<可选的独立 UID 大纲绝对路径>" \
  --supporting-source "<页级说明绝对路径>::P02,P05" \
  --supporting-source "<共享标题合同绝对路径>::deck" \
  --anchor-approval-scope style_anchor_only
```

有锚点时增加 `--anchor "<primary 绝对路径>::primary"`，需要 supporting 时再增加一次 `--anchor "<绝对路径>::supporting"`。没有锚点时不传 `--anchor`，控制面使用内部机械席位 A，但明确记录视觉家族来自导演而非已选候选。没有独立 UID 文件时省略 `--slide-identity-file`。该文件只供 source snapshot 与 handoff 绑定候选身份，不进入 Director、ImageGen、Judge 或重试。每个 supporting source 必须显式声明目标页或 `deck`；页级说明只进入对应页面，明确共享的标题合同只在 packet 顶层出现一次。`--anchor-approval-scope` 省略时默认 `style_anchor_only`；只有存在锚点且用户明确把它同时批准为最终页时才改用 `final_page_and_anchor`。`--overview-python` 省略时只尝试当前解释器；当前解释器不能导入 Pillow 就明确报错，不扫描其他环境路径。

```text
state/selected_style_run_state.json
state/director_inputs/authoritative_expansion_packet.json
state/director_inputs/content_bundle.raw.json
state/director_inputs/chrome_assets_bundle.raw.json
state/director_inputs/visual_family_plan.raw.json
state/source_snapshot.json
selected_style_contract.json
content_contracts/
page_jobs/
page_jobs/repair_jobs/
style_jobs/results/
visual_qa_jobs/
visual_qa_jobs/selected_style_judge.json
visual_qa_jobs/results/selected_style_judge_report.json
origin_image/
overview/
```

initializer 同时写入起始事件、`project_dir`、`run_id`、规范页序、`run_mode=selected_style_expansion` 与运行时绑定。之后所有工程路径只从 state 的绝对路径和 `project_dir` 推导；根任务不得再手传第二套目录、job 或 overview 路径。

一次冻结本轮 target-page-only packet v2：只含本次请求页面各自的 `exact_text`、该页 supporting sources，以及确实适用且仅出现一次的 deck 共享合同；未请求页面、整纲副本、历史稿和维护文件不得进入 packet。若 deck JSON 合同携带全稿 `include|exclude|applies_to|page_ids` 或逐页映射，initializer 只做页码集合与本轮 target page ids 的机械交集并删除未请求页键，不猜标题语义，也不修改上游合同。归一化文本与哈希只用于身份，导演读取保留精确标点的 `exact_text`。三位导演只读同一 packet，不再读取会变化的完整上游大纲。packet 冻结后，上游后续修改只影响新运行；本轮只校验冻结 packet、内容合同、正式 job、实际附件、receipt 与最终 PNG。

## 三位导演

三位导演并行、短生命周期、互不覆盖 raw 文件；都不得调用 ImageGen、修改正式 state 或替另一席做决定。根任务不再抄写一套合并结果。

控制面负责补齐能机械确定的 schema 默认值，导演把时间留给事实、关系与视觉判断。若某一导演长时间没有产生有效 raw，只中断并以同一冻结 packet、同一唯一输出路径重启该导演一次；其他已完成导演继续复用，不重启三席或整轮。根任务不得手写事实、关系或视觉 raw 来绕过导演。

### 事实内容导演

固定使用 `gpt-5.6-sol/high` 和 `prompts/selected-style-content-director.md`。逐页只看当前页原文与当前页说明，并只写：

- `source_facts`、`display_required`、`display_flexible`、`flexible_story`；
- 来源状态、语言、语义不变量、禁止误读边界；
- 内容负载、`spatial_feasibility` 与需要用户决定的内容问题。

不写风格、关系命题、布局、锚点适配、global chrome 或资产路由。

### 标题与资产导演

固定使用 `gpt-5.6-terra/medium` 和 `prompts/selected-style-chrome-assets-director.md`。只在用户或冻结来源明确授权时，才在唯一 `chrome_assets_bundle.raw.json` 中写 `global_chrome_contract_raw`；普通锚点中的 Logo、标题区、页眉或底栏不构成授权。授权合同时必须一次写全 `authorization.status=authorized` 对象、scope、required/policy 与非空 `prompt_briefs.zh|en`，不让根任务补字段。逐页 `canonical_titles` 保持 null，由 `prepare-directors` 从事实内容合同的逐字 `title` 机械投影，避免两位导演重复抄标题。控制面再确定性编译正式 `global_chrome_contract.normalized.json`，根任务不另抄第二份。资产必须显式声明 `asset_usage=render_asset|planning_evidence`：只有确实要出现在成图中的 Logo、产品图或授权现场图可作为 raster 附件；旧片截图、旧架构图、旧组织图等 planning evidence 只冻结为规划来源，不进入 ImageGen 附件。

### 全稿视觉导演

固定使用 `gpt-5.6-sol/high` 和 `prompts/selected-style-visual-director.md`。有锚点时可在隔离子 Agent 中查看一至两张；没有锚点时只读冻结内容、用户审美要求和品牌约束。写一份 `selected_style_family_contract` 和逐页唯一视觉计划。每页至少包含：

- `relationship_thesis`
- `visual_quality_intent`
- `craft_axis`
- `visual_activity_mode`
- `attention_strategy`
- 正向 `spatial_topology_intent`
- `page_adaptation_brief`
- `anchor_input_mode=raster|text_family`
- `representation_disclosure.mode=none|visible`；visible 时给出源语言可见字样与正向依据

视觉导演以软性跨页节奏避免相邻页机械复用同一内容区骨架，不设 Fast8 式数量配额，也不把抽象程度、密度、媒介或布局模板锁成家族不变量。

## 确定性控制面

三位导演退出后，新运行只使用三个规范动作：

```bash
python3 scripts/selected_style_control_plane_v1.py prepare-directors \
  --state "<project_dir>/state/selected_style_run_state.json"

python3 scripts/selected_style_control_plane_v1.py render-action \
  --state "<project_dir>/state/selected_style_run_state.json"

python3 scripts/selected_style_control_plane_v1.py lean-finalize \
  --state "<project_dir>/state/selected_style_run_state.json"
```

`prepare-directors` 只做窄规范化与共享主干合并：校验固定版本、已知别名、规范页码、路径根、同路径资产去重、内容 v2、prompt v4、`creative_brief_projection`、来源快照、正式 jobs、附件 manifest 与输入指纹。准备身份绑定 packet、三个 raw、合同、jobs 与 source snapshot 的哈希；重复调用返回 `already_prepared`，不得重置 active、已完成或终态页面，也不得重复追加事件。它不得猜测事实、关系、锚点兼容性、视觉媒介、披露或标题授权，也不得覆盖三个 raw 文件。

`render-action` 只返回或执行共享管线的规范机械动作。`lean-finalize` 在 Judge 通过或一次 delta review 收口后，完成已验收页的文件/尺寸/哈希门、总览和必要交付；完整计时、健康报告和监测后置，不阻断已经验收的页面。

## prompt v4 与附件

所有新页从 v2 内容合同和视觉计划机械编译 prompt v4：

- `display_required` 投影为逐字 `literal_anchors`；
- `display_flexible` 由内容导演压缩为自然语言 `flexible_story`；
- `creative_brief_projection` 保存当前页的关系命题、质量意图、工艺轴、视觉活跃度、注意力策略、正向空间拓扑和适配 brief；
- 提示只描述当前页要表达的事实、关系与正向视觉意图，不列其他页或锚点中的旧词汇作为护栏；
- `global_chrome` 只有明确授权时才投影，并只向当前页投影其标题和必要 Logo。

每次 ImageGen 最多 5 个真实光栅附件。路由优先级固定为：

1. 当前页事实或品牌必须使用的 `required_page_assets`；
2. 已授权 global chrome 的必要 Logo；
3. 存在时的 primary 风格锚点；
4. 存在时的 supporting 风格锚点。

同路径只传一次。零锚点运行所有页强制为 `text_family`。`anchor_input_mode=text_family` 时附件清单不得含风格锚点，但仍保留必要页面资产；`raster` 时先传导演锁定的固定锚点集合。控制面按正式解析出的真实附件机械处理容量：先移除 supporting 锚点；若事实/品牌必要资产本身已占满 5 个，再把该页有效模式降级为 `text_family`。不得根据未解析的计划资产提前降级，也不得丢弃事实或品牌必要资产。

每个渲染资产按导演声明的 `role` 与 `use` 编译为正向附件用途，不能笼统要求“所有资产原样使用”。planning evidence 只进入冻结来源与事实合同。视觉导演显式选择写实情境重建且没有授权现场照片时，`representation_disclosure.visible_text` 同时进入 `display_required` 和 prompt v4；真实授权照片页不自动添加，脚本不按关键词推断。

## 机械执行与恢复

正式 jobs 锁定后只创建一个图片执行 Agent，使用 `prompts/selected-style-burst-runner.md` 的 canonical wrapper，并且每次 run 只启动一次 wrapper。不要为每页创建 LLM Worker。wrapper 通过共享 `prepare-next`、`Promise.race` 滚动补位和 exec session drain 循环到整个 run 终态；所有页复用共享 `claim → ImageGen → savedPath/receipt → release`、PNG 校验、技术重试、无生图恢复和中央 JIT 槽位表。真实 ImageGen 同时最多 5 路，cap5 不是总页数上限；任何命令或 receipt 异常都在 `finally` 释放 claim。兼容字段 `active_child_limit` 固定不随页数扩张，真实席位是 `executor_agents=1`、`judge_agents=1`。单页失败不取消其他已经启动的页面。

duplicate claim、已有 receipt、错页、错 job 或输入指纹变化都必须停止对应页的第二次正常生图。ImageGen 完成但交接异常时先做无生图恢复；明确网络或工具失败才按既有技术预算重试。队列不能完成时确定性排空并释放租约。

页面内容需要更新时创建明确的新 revision/job；旧冻结 job 不修改、不覆写。页面级 packet、合同、正式 job 或附件不一致只阻断该页，不使其他已冻结且无关页面失效。

## 单一 Judge 与一次定向修复

只保留一个 `gpt-5.6-terra/low` 有界隔离 Judge，使用 `prompts/selected-style-judge.md`。本版在全部页面结算后启动 Judge，不声称与后续生成波次重叠。Judge 只看一次控制面锁定的 contact sheet，只有明确硬伤疑点才看必要单图，整轮最多打开 6 张；不为确认正常页逐页放大，不重复读取已经通过的页面。完成必要的疑点单图检查后，Judge 才一次性写入最终报告 JSON；报告文件一旦存在即视为终局，不得先写 placeholder、pending 或中间版。图片载荷留在 Judge 子 Agent 内。

Judge 区分技术健康与视觉正确性，并检查：

- 当前页来源明确的 `title` 是唯一视觉主标题；`subtitle` 未授权时不得继承锚点或附件副标题。只差无语义影响的末尾 `。.;；` 不返工，除非当前合同明确要求标点逐字一致。

- 事实和关系硬伤、`display_required`、`display_flexible`；
- Logo、标题、必要资产与 `final_page_and_anchor` 的当前页义务；
- 锚点或其他页文字、对象、数字、标题和语义污染；
- 同一视觉家族是否成立，同时媒介、密度和拓扑是否按内容适配；
- 明显跨页机械复制、严重构图或工艺退化；
- 裁切、乱码、重叠、水印、错误资产和无效 PNG。

轻微瑕疵、主观偏好、参考图“不够像”或“还可以更漂亮”不触发修复。只对明确失败页创建一次定向 repair job，并保存 `must_change`、`invariants` 与输入策略：普通局部视觉编辑可保留失败候选；语义污染修复不得回灌失败候选，明确由 raster 锚点旧文字导致时同时移除该 raster 并以 `text_family` 重生。修复后只做 delta review。需要内容决定的单页标记为待决，不阻塞其他页面继续生成和验收。

## 收口与媒体隔离

根任务只读精简 JSON、绝对路径、尺寸、哈希和状态，不打开锚点、候选、单图或 contact sheet。图片执行 Agent 与 Judge 可以在各自隔离上下文中接收或查看必要图片，但不得向父级回传图片块、缩略图、Base64、data URI 或原始 JSONL。

所有已要求且无待决的页面通过后运行 `lean-finalize`。它必须幂等：重复调用不得重生图、换 job、重写 raw director 输出或改变已封存的输入身份。最终只用普通可点击文件链接交付总览和页面；handoff 与健康报告可以后置，但不得把 `candidate_ready` 或文件校验写成已经完成视觉批准。

旧扩页只作只读归档；如需继续生成或修复，基于当前权威来源和锚点建立新的 `selected_style_expansion`，不得迁移或改写旧运行。
